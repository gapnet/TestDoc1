Template for the Read the Docs tutorial
=======================================

This GitHub template includes fictional Python library
with some basic Sphinx docs.

Read the tutorial here:

https://docs.readthedocs.io/en/stable/tutorial/

Video Generator Utility
-----------------------

This project also includes a utility for generating simple YouTube videos featuring quotes,
background visuals, and lofi music.

For detailed instructions on how to use this utility, please see the
`video_generator/README.md <video_generator/README.md>`_ file.
